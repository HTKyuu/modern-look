Accordion

Native details and summary, so it works without JavaScript and is keyboard accessible by default.

Why native details?

It is focusable, toggles with Enter and Space, announces its state, and needs no script. We only style it.

Can several be open at once?

Yes by default. Add a shared name attribute to the details elements if you want only one open at a time.

Dialog

Native dialog opened with showModal(): focus is trapped, Escape closes, focus returns to the opener. Clicking the backdrop also closes.

Share this report

Anyone with the link can view the report for 30 days. They cannot edit it.

Delete the March report?

This removes the report and its share links. The underlying bookkeeping data is not affected.
